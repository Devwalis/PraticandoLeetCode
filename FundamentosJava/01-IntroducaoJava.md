# 📘 Fundamentos da Linguagem Java

## 1️⃣ Introdução ao Java

### 📌 O que é Java

Java é uma **linguagem de programação de alto nível**, criada para ser:

- Portável  
- Robusta  
- Segura  
- Orientada a Objetos  

Ela permite o desenvolvimento de aplicações que podem ser executadas em diferentes sistemas operacionais **sem necessidade de reescrita do código-fonte**.

Java é utilizada tanto no **desenvolvimento acadêmico** quanto no **mercado profissional**, sendo uma das linguagens mais populares do mundo.

---

### 🎯 Objetivo da Linguagem Java

O principal objetivo do Java é permitir que um programa seja:

- Desenvolvido uma única vez  
- Executado em qualquer plataforma compatível  

Isso é possível graças ao uso da **Java Virtual Machine (JVM)**, que abstrai as diferenças entre sistemas operacionais e arquiteturas de hardware.

Além disso, Java foi projetada para:

- Facilitar o desenvolvimento de sistemas grandes  
- Incentivar boas práticas de programação  
- Reduzir erros comuns através de **forte tipagem** e **gerenciamento automático de memória**

---

### 🌍 Onde Java é Utilizado

Java é amplamente utilizado em diversas áreas da computação, como:

- **Aplicações Web**
  - Back-end de sistemas corporativos
  - APIs REST

- **Aplicações Desktop**
  - Sistemas administrativos
  - Ferramentas internas

- **Aplicações Mobile**
  - Base do sistema Android

- **Sistemas Corporativos**
  - Bancos
  - Fintechs
  - Sistemas governamentais

- **Sistemas Distribuídos**
  - Microserviços
  - Aplicações em nuvem

Essa ampla utilização se deve à sua **estabilidade**, **escalabilidade** e ao grande **ecossistema de bibliotecas e frameworks**.

---

### ♻️ Filosofia “Write Once, Run Anywhere”

A filosofia **“Write Once, Run Anywhere” (WORA)** significa:

> Um programa Java pode ser escrito uma única vez e executado em qualquer ambiente que possua uma JVM compatível.

#### Como isso funciona?

1. O código Java é escrito em arquivos `.java`
2. O compilador Java transforma esse código em **bytecode**
3. O bytecode é executado pela **JVM**
4. Cada sistema operacional possui sua própria implementação de JVM

Isso garante:

- Portabilidade  
- Independência de plataforma  
- Maior vida útil do software  

---

### 📎 Conclusão do Tópico

A introdução ao Java apresenta a linguagem como uma solução **robusta e multiplataforma**, ideal para o desenvolvimento de aplicações modernas.

Compreender esses conceitos iniciais é essencial antes de avançar para aspectos técnicos como **sintaxe**, **estrutura de programas** e **orientação a objetos**.
