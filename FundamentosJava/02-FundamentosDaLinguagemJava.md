## 2️⃣ Histórico da Linguagem Java

### 📌 Origem da Linguagem Java

A linguagem Java surgiu no início da década de 1990, em um projeto desenvolvido pela empresa **Sun Microsystems**.

O projeto original recebeu o nome de **Green Project** e tinha como objetivo criar uma linguagem que pudesse ser utilizada em dispositivos eletrônicos diversos, como televisores, aparelhos domésticos e sistemas embarcados.

Inicialmente, a linguagem foi chamada de **Oak**, em referência a uma árvore que ficava em frente ao escritório de um dos criadores. Posteriormente, o nome foi alterado para **Java** por questões legais.

---

### 👨‍💻 Criadores do Java

Java foi criada por uma equipe liderada por:

- **James Gosling** (principal idealizador)
- Mike Sheridan
- Patrick Naughton

James Gosling é frequentemente chamado de **“pai do Java”**, devido à sua forte participação na definição da linguagem e de seus principais conceitos.

---

### 📅 Ano de Criação e Lançamento

- **Início do desenvolvimento:** 1991  
- **Primeiro lançamento oficial:** 1995  

O lançamento do Java em 1995 marcou um momento importante na história da computação, principalmente com o crescimento da **Internet** e da necessidade de aplicações portáveis.

---

### 🌐 Crescimento e Popularização

Java ganhou destaque rapidamente por causa de algumas características inovadoras para a época:

- Execução independente de plataforma
- Segurança reforçada
- Uso da Máquina Virtual (JVM)
- Forte suporte à Orientação a Objetos

Inicialmente, Java foi amplamente utilizado para aplicações web interativas (applets), mas com o tempo passou a ser adotado em sistemas corporativos, servidores, aplicações desktop e, posteriormente, no desenvolvimento mobile.

---

### 🔄 Evolução da Linguagem

Com o passar dos anos, Java passou por diversas evoluções, acompanhando as necessidades do mercado e da tecnologia:

- Expansão para sistemas corporativos de grande escala
- Melhoria de desempenho da JVM
- Introdução de novos recursos na linguagem
- Ampliação do ecossistema de bibliotecas e frameworks

Em **2010**, a **Oracle Corporation** adquiriu a Sun Microsystems e passou a ser a principal responsável pela manutenção e evolução da plataforma Java.

---

### 📎 Importância Histórica do Java

Java se consolidou como uma das linguagens mais importantes da história da computação por:

- Influenciar outras linguagens modernas
- Ser amplamente adotada no meio acadêmico
- Manter relevância no mercado por décadas
- Sustentar grandes sistemas corporativos ao redor do mundo

Seu modelo baseado em **JVM**, **bytecode** e **portabilidade** continua sendo referência até hoje.

---

### 📎 Conclusão do Tópico

O histórico da linguagem Java mostra como ela foi pensada desde o início para ser **portável, robusta e duradoura**.

Compreender sua origem e evolução ajuda a entender por que Java é fortemente associada a **boas práticas**, **orientação a objetos** e **desenvolvimento de sistemas de grande escala**.
