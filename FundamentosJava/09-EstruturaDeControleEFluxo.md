# 📘 Fundamentos da Linguagem Java

## 9️⃣ Estruturas de Controle de Fluxo

### 📌 Visão Geral

As estruturas de controle de fluxo determinam **a ordem em que as instruções de um programa são executadas**.  
Em Java, elas permitem tomar decisões, repetir blocos de código e controlar o comportamento do programa conforme determinadas condições.

Essas estruturas são fundamentais para a construção de algoritmos e para a implementação da lógica de sistemas.

---

## 🔀 Estruturas de Decisão

As estruturas de decisão permitem executar diferentes blocos de código de acordo com uma condição.

---

### 🔹 Estrutura `if`

A estrutura `if` executa um bloco de código **somente se a condição for verdadeira**.
