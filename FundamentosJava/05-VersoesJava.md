## 5️⃣ Versões do Java

### 📌 Visão Geral

Desde seu lançamento, o Java passou por diversas versões, cada uma trazendo melhorias de desempenho, segurança e novos recursos para a linguagem e para a plataforma.

Compreender as versões do Java é importante para entender a **evolução da linguagem**, sua **compatibilidade** e sua **utilização no mercado**.

---

### 🧩 Edições da Plataforma Java

A plataforma Java é dividida em diferentes edições, cada uma voltada para um tipo específico de aplicação.

#### ☕ Java SE (Standard Edition)

É a edição base da plataforma Java, utilizada para:

- Aplicações desktop
- Aplicações de linha de comando
- Base para outras edições

Contém as bibliotecas fundamentais da linguagem e é o ponto de partida para qualquer desenvolvedor Java.

---

#### 🌐 Java EE / Jakarta EE (Enterprise Edition)

Voltada para o desenvolvimento de **aplicações corporativas e web**, incluindo:

- Sistemas distribuídos
- Aplicações de grande escala
- APIs para servidores de aplicação

Atualmente, essa edição é conhecida como **Jakarta EE**.

---

#### 📱 Java ME (Micro Edition)

Destinada a dispositivos com recursos limitados, como:

- Dispositivos embarcados
- Sistemas embarcados
- Dispositivos antigos com pouca capacidade de processamento

Hoje, seu uso é mais restrito quando comparado às outras edições.

---

### 📅 Linha do Tempo das Principais Versões

Ao longo dos anos, o Java recebeu diversas versões importantes. Algumas delas marcaram a evolução da linguagem:

- **Java 1.0 (1996)** – Primeira versão oficial
- **Java 2 (1998)** – Introdução das edições SE, EE e ME
- **Java 5 (2004)** – Generics, enums e anotações
- **Java 7 (2011)** – Melhorias de desempenho e linguagem
- **Java 8 (2014)** – Expressões lambda e programação funcional
- **Java 11 (2018)** – Versão LTS amplamente adotada
- **Java 17 (2021)** – Versão LTS moderna
- **Java 21 (2023)** – Versão LTS mais recente

---

### 🕒 Versões LTS (Long Term Support)

As versões **LTS (Long Term Support)** recebem suporte por um período mais longo, incluindo:

- Atualizações de segurança
- Correções de bugs
- Estabilidade para uso em produção

Essas versões são as mais utilizadas no mercado corporativo.

Exemplos de versões LTS:

- Java 8  
- Java 11  
- Java 17  
- Java 21  

---

### ⚠️ Importância da Compatibilidade

Java mantém um forte compromisso com **compatibilidade retroativa**, permitindo que:

- Códigos antigos continuem funcionando em versões mais novas
- Sistemas legados sejam mantidos por longos períodos

Esse fator contribui para a longevidade da linguagem e sua ampla adoção em empresas.

---

### 📎 Conclusão do Tópico

As versões do Java refletem a evolução contínua da linguagem e da plataforma.

Conhecer as edições, versões e o conceito de **LTS** é fundamental para escolher corretamente a versão a ser utilizada em estudos, projetos pessoais ou aplicações profissionais.
