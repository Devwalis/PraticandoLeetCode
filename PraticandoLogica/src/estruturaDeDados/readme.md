# 📌 Estruturas de Dados — Classe Vetor

## 📎 Introdução  
O **Vetor** é uma estrutura de dados que armazena elementos de forma sequencial em posições contíguas na memória. Cada elemento é acessado diretamente por meio de um índice.

---

## 🔖 Tópicos Documentados

### ✔️ Definição  
- O que é um vetor  
- Acesso rápido aos elementos via índice  
- Estrutura com tamanho fixo (em sua forma tradicional)

---

### ✔️ Adicionar elemento ao final do vetor  
- Inserir na próxima posição livre  
- Caso o vetor esteja cheio, é necessário aumentar a capacidade

---

### ✔️ Verificar quantidade de elementos no vetor  
- Uso de variável de controle `tamanho`
- Diferença entre **tamanho atual** e **capacidade máxima**

---

### ✔️ Imprimir elementos do vetor  
- Percorrer e exibir cada elemento armazenado no vetor

---

### 🔄 Obter elemento de uma posição *(Em andamento)*  
- Acesso via índice específico
- Verificação de índices inválidos

---

### 🔍 Verificar se elemento existe no vetor *(Em andamento)*  
- Busca sequencial até encontrar o valor desejado
- Retorno da posição ou indicação de não encontrado

---

### ➕ Adicionar elemento em qualquer posição *(Em andamento)*  
- Deslocamento de elementos para abrir espaço
- Ajuste do tamanho

---

### 📈 Adicionar mais capacidade ao vetor *(Em andamento)*  
- Criar novo vetor maior
- Copiar todos os elementos

---

### ❌ Remover elemento do vetor *(Em andamento)*  
- Deslocar elementos para ocupar o espaço da remoção
- Atualização da variável de tamanho

---

### 🧩 Generalizar o tipo dos elementos *(Em andamento)*  
- Implementação com **Generics**
- Compatibilidade com qualquer tipo de objeto

---

### 🔁 Definindo o tipo do vetor dinamicamente *(Em andamento)*  
- Escolha do tipo ao instanciar o vetor
- Reutilização da estrutura

---

- Forma dinâmica de vetor
